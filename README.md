# AprilTag Detector Web Application

This is a web-based application that uses your device's camera to detect AprilTags from the 36h11 family in real-time. It's designed for indoor location tracking and similar applications.

The core detection logic is powered by the AprilTag C library, which has been compiled to WebAssembly (WASM) for high-performance execution in the browser.

## Features

-   Real-time AprilTag detection from a camera feed.
-   Client-side processing with no server-side dependency for detection.
-   Uses WebAssembly for near-native performance.
-   Overlays detected tags with bounding boxes and their IDs on the video stream.

## Running Locally

Since the application uses JavaScript modules that are fetched by the browser, you need to serve the files from a local web server. You cannot simply open the `index.html` file directly from your file system.

1.  **Navigate to the project directory:**
    Open your terminal or command prompt and change into the directory where you have cloned these files.

2.  **Start a simple web server:**
    If you have Python 3 installed, you can easily start a web server with the following command:
    ```bash
    python3 -m http.server 8000
    ```
    This will start a server on port 8000.

3.  **Open the application in your browser:**
    Open your web browser and navigate to:
    [http://localhost:8000](http://localhost:8000)

4.  **Grant camera permissions:**
    The browser will prompt you for permission to use your camera. You must grant permission for the application to work.

## Deployment to Vercel

This project is a static web application and can be easily deployed to [Vercel](https://vercel.com) for free.

1.  **Push to a GitHub Repository:**
    Make sure all the project files (`index.html`, `style.css`, `main.js`, `apriltag.js`, `apriltag_wasm.js`, `apriltag_wasm.wasm`) are pushed to a GitHub repository.

2.  **Sign up/Log in to Vercel:**
    Go to the Vercel website and create an account or log in. It's easiest to sign up using your GitHub account.

3.  **Import Your Project:**
    -   From your Vercel dashboard, click on "**Add New...**" -> "**Project**".
    -   Select the GitHub repository you just created/pushed to.

4.  **Configure the Project:**
    -   Vercel will automatically detect that this is a static site and will not require a specific framework preset or build command. The default settings should work perfectly.
    -   You do not need to configure any build commands or output directories.

5.  **Deploy:**
    Click the "**Deploy**" button. Vercel will build and deploy your site, providing you with a public URL once it's finished.

## Project Files

-   `index.html`: The main structure of the web page.
-   `style.css`: Provides styling for the application's UI.
-   `main.js`: Handles camera setup, video processing, and rendering detections on the canvas.
-   `apriltag.js`: A JavaScript class that wraps the WASM module for easy use.
-   `apriltag_wasm.js`: Glue code generated by Emscripten to load and run the WASM module.
-   `apriltag_wasm.wasm`: The compiled WebAssembly binary containing the AprilTag detection logic.
